# 쉼터 — 승무원 온라인 힐링공간

열차 승무원이 쉬는 시간에 들어와 머무는 3D 공간이다. 채팅은 없고, 서로의 **위치와 행동(이모트)** 만 보인다. 행동에는 쿨타임이 있다. 짧은 글은 **풍등**에 담아 날릴 수만 있다 (저장하지 않음).

- Vite + Three.js(TypeScript), 모바일 세로 화면 전용
- 서버 없이 [Trystero](https://github.com/dmotz/trystero)(WebRTC P2P, Nostr 시그널링)로 사용자끼리 직접 연결
- `main`에 push하면 GitHub Actions가 GitHub Pages에 배포
- 근무앱은 배포 주소를 웹뷰로 띄우기만 하면 된다 (연동 없음)

## 개발

```bash
npm install
npm run dev     # http://localhost:5173  (?cap=2 로 방 정원을 줄여서 분할 테스트)
npm test        # 단위 테스트 (쿨타임/도배 필터/프로토콜/방 분할)
npm run build   # dist/
```

개발 모드(`npm run dev`)는 실제 서비스와 다른 공간(`APP_ID`에 `-dev`)을 써서 테스트 아바타가 실사용자 방에 섞이지 않는다. 콘솔에서 `__space.room`, `__space.peers`, `__space.spam('wave', 20)`(쿨타임을 우회한 도배 테스트)를 쓸 수 있다.

## 배포 (GitHub Pages)

1. GitHub에 저장소를 만들고 push한다 (무료 플랜은 **public 저장소**여야 Pages를 쓸 수 있다).
2. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 바꾼다.
3. `main`에 push하면 `.github/workflows/deploy.yml`이 테스트 → 빌드 → 배포를 실행한다.
4. 주소는 `https://<계정>.github.io/<저장소>/` 이다. 이 주소를 근무앱 웹뷰에 넣는다.

## 공간 컨셉

입장할 때 컨셉을 고른다. 지난번에 고른 컨셉에는 '지난번' 표시가 붙는다. 왼쪽 위 ⇄ 버튼을 누르면 다시 고를 수 있다.
컨셉마다 방이 따로라서 **같은 컨셉을 고른 사람끼리만** 만난다.

새 컨셉을 추가하는 방법: `src/scene/themes/`에 `ThemeDef`(이름, 설명, 카드 배경, 가운데 장애물 반지름, 카메라 위치, 소리, `build`)를 만들고, `src/scene/World.ts`의 `THEMES`에 넣는다.

## 앉기 / 눕기 (산속 캠핑)

- 모닥불 둘레의 **캠핑 의자 6개**를 누르면 걸어가서 앉는다. **텐트 2동**(각 2자리)을 누르면 들어가서 눕는다.
- 바닥을 누르면 일어나서 걸어간다. 앉거나 누운 상태에서도 행동(손인사·하트 등)을 할 수 있다.
- 내가 텐트에 누우면 내 화면에서만 그 텐트가 반투명해져서 누워 있는 내 모습이 보인다. 다른 사람에게는 텐트 문 밖으로 다리가 나온 모습으로 보인다.
- 이미 누가 있는 자리를 누르면 "이미 다른 분이 앉아 있어요"라는 안내가 뜬다.
- 두 사람이 동시에 같은 자리를 잡으면 정해진 규칙(peerId 비교)으로 한 명이 양보한다. 양쪽이 같은 계산을 하므로 따로 메시지를 주고받지 않는다.
- 자리는 테마의 `spots` 배열에 정의하고, 네트워크로는 자리 번호(정수)만 오간다. 이전 버전과 호환된다.

### 마시멜로 굽기

- 의자에 앉아 왼쪽 아래 🍢 버튼으로 10초 동안 마시멜로를 구울 수 있다.
- 꼬치를 든 모습과 노릇해지는 마시멜로가 같은 공간의 다른 사람에게도 보인다.

## 풍등 날리기

- 오른쪽 아래 🏮 버튼 → 20자 이내로 글을 쓰거나 예시 문구를 골라 **날리기**. 내 머리 위에서 풍등이 떠올라 천천히 먼 하늘로 흘러가고, 약 40초 뒤 사라진다. 글씨는 처음 18초만 보인다.
- **저장하지 않는다.** 그 순간 같은 방에 있던 사람만 본다. 나중에 들어온 사람에게는 보이지 않는다.
- 한 사람이 **1분에 1개**. 받는 쪽도 같은 쿨타임을 검사해서, 조작된 클라이언트가 연달아 보내도 무시한다 (계속 어기면 그 사람을 숨김).
- 글 검사는 보내는 쪽과 받는 쪽이 같은 함수(`checkLanternText`)로 한다. 필터를 건너뛰고 보낸 글은 받는 쪽에서 버려지고 위반으로 기록된다.
  - 금칙어: 띄어쓰기·숫자·기호·초성·전각 문자로 바꿔 써도 걸린다 (`씨 발`, `씨1발`, `ㅅㅂ`, `ｓｈｉｔ`).
  - 연락처·링크: 숫자 4개 이상, `.com`·`www`·`@` 등은 담을 수 없다.
  - 한글·영문·숫자·기본 문장부호·이모지만 허용한다.
- 다른 사람의 풍등을 누르면 **가리기**를 고를 수 있다. 이번 접속 동안 그 사람의 풍등이 내 화면에 보이지 않는다.
- 내 풍등을 날리면 카메라가 몇 초 동안 살짝 하늘을 올려다본다.
- 금칙어 필터는 완벽하지 않다. 운영하면서 걸러야 할 말이 생기면 `src/lantern/filter.ts`의 `BLOCKED_WORDS`에 더하고 push하면 된다.

## 별 받기 게임

- 컨셉 선택 화면의 **별 받기 게임** 카드로 입장한다. 3D 공간이 아닌 모바일 탭 게임 화면으로 바뀐다.
- 30초 동안 떨어지는 **별(+10점)** 을 누르고 **폭탄(−20점)** 을 피한다. 점수는 0 아래로 낮아지지 않고, 후반에는 별이 더 자주 빠르게 떨어진다.
- 같은 방에 있는 사람들의 현재 라운드 점수를 실시간으로 받아 순위를 보여준다. 각자 독립적으로 30초 라운드를 시작하고 다시 도전할 수 있다.
- 최고 점수는 기기에 저장한다. 네트워크가 끊겨도 혼자 플레이할 수 있다.

## 지하철 퇴치대

- **3분 생존형 싱글 플레이 슈팅 게임**이다. 가상 조이스틱이나 방향키·WASD로 이동하면 가장 가까운 빌런에게 자동으로 탄환을 발사한다.
- 기본 추적형, 빠른 빌런, 높은 HP의 탱커와 60초에 등장하는 막차 빌런이 시간에 따라 더 많이 몰려온다.
- 빌런을 처치하고 경험치 보석을 모아 레벨업하면 발사 속도·공격력·다중 발사·관통·회복 등 3개의 강화 선택지 중 하나를 고른다.
- 빌런과 접촉하면 HP이 감소하며 0이 되면 종료된다. 일시정지와 재도전을 지원하고 최다 처치·최대 생존 시간을 기기에 저장한다.

## 소리

음원 파일 없이 Web Audio로 합성한다. 다운로드 용량이 늘지 않고, 라이선스 걱정도 없다.

| 컨셉 | 배경 소리 | 발소리 |
| --- | --- | --- |
| 해 질 녘 광장 | 산들바람, 나뭇잎, 새소리, 멀리 귀뚜라미 | 풀 밟는 소리 |
| 산속 캠핑 | 모닥불 타는 소리와 탁탁 튀는 소리 (불에서 멀어지면 작아짐), 귀뚜라미, 밤바람, 가끔 부엉이 | 흙·마른 잎 밟는 소리 |

- 다른 사람 발소리도 가까이 있을 때 작게, 왼쪽/오른쪽 방향에 맞춰 들린다.
- 오른쪽 위 🔊 버튼으로 켜고 끈다. 설정은 기억한다 (기본값은 켜짐).
- 모바일 정책상 소리는 사용자가 화면을 누른 순간에만 켤 수 있다. 그래서 컨셉 카드를 누를 때 함께 켠다.
- 앱이 백그라운드로 가거나 소리를 끄면 오디오 처리를 멈춰 배터리를 아낀다.
- iOS에서는 기기가 무음 모드이면 웹 소리도 나지 않는다.

## 도배 방지 방식

서버가 없기 때문에 두 군데에서 막는다.
- **보내는 쪽**: 행동별 쿨타임 + 10초에 4회 전역 제한. 쿨타임 중인 버튼은 잠긴다.
- **받는 쪽**: 같은 기준(지연 오차 허용)으로 걸러서 화면에 그리지 않는다. 계속 어기는 피어는 그 세션 동안 숨긴다.

그래서 누가 클라이언트를 조작해서 도배를 보내도 다른 사람 화면에는 정상 속도로만 보인다.

## 운영 메모

- **연결 실패가 잦을 때**: 통신사·사내망 NAT 때문에 P2P 연결이 안 되는 경우가 있다. `src/config.ts`의 `TURN`에 TURN 서버를 추가한다.
- **Nostr 릴레이가 불안정할 때**: `src/net/strategy.ts`에서 `@trystero-p2p/mqtt`로 바꾼다.
- **접근 제한 없음**: 주소를 아는 사람은 일반 브라우저로도 들어올 수 있다. 페이지에 링크·공유·선택·길게 누르기 메뉴가 없고, 검색엔진 색인도 막혀 있다.
- **근무앱 쪽 권장 설정 (선택)**: 릴리스 빌드에서 웹뷰 디버깅을 끈다 (iOS `isInspectable = false`, Android `WebView.setWebContentsDebuggingEnabled(false)`). iOS는 `allowsLinkPreview = false`도 설정한다. WebRTC DataChannel은 iOS 14.3 이상 WKWebView와 Android WebView에서 동작한다.
